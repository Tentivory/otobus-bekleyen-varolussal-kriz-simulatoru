# Otobüs Bekleyen Varoluşsal Kriz Simülatörü

Bu proje, insanlığın en temel deneyimlerinden birini simüle eder: **otobüs beklemek**. 

Otobüs gelmez. Sen beklersin. Zaman geçer. Düşünceler başlar. Varoluş sorgulanır. Kahve soğur. Hayat devam eder mi? Bilinmez.

## Nasıl Çalışır?

```bash
python otobüs_bekleyici.py
```

Program sonsuz döngüde otobüs bekler. Her dakika (veya saniye) biraz daha varoluşsal kriz yaşarsın. Çünkü otobüs, tıpkı adalet gibi, her zaman gecikir.

## Özellikler

- Otobüs asla gelmez (gerçekçi simülasyon)
- Artan varoluşsal düşünceler
- Rastgele "belki şimdi gelir" umut kırılmaları
- Gizli mesajlar (sadece dikkatli okuyanlar görür)
- Çalışır. Gerçekten çalışır. Otobüs gelmese de kod çalışır.

## Uyarı

Bu simülatör gerçek hayattaki otobüs beklemeyi ikame etmez. Gerçek hayatta otobüs belki gelir. Belki.
